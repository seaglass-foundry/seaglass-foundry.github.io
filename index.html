Flagship · ForgeGIS™

GPU-accelerated geospatial compute, for the agent era

Raster, hydrology, and point-cloud work on the GPU, a large vector and topology library in pure Java — all callable by a person or an AI agent.

ForgeGIS runs raster, hydrology, visibility, spectral, ML, and point-cloud workloads on the GPU, alongside a large vector and topology library, and hands almost its entire catalog to AI agents through a native Model Context Protocol server. It ships as ordinary Java libraries: no first-party native code, no GDAL bindings, nothing extra to install. A pipeline engine imports QGIS models and runs branching raster and vector workflows, keeping raster data on the GPU from start to finish.

As of August 2026, the only commercially-supported GPU-accelerated geospatial MCP server we have been able to identify.

ForgeMind™

Natural language to validated GPU pipelines — or an honest refusal

The natural-language control plane for ForgeGIS. It compiles a plain-language request into a validated, executed pipeline on the GPU-accelerated engine, and refuses by construction when a request cannot be honored correctly. Across its June 2026 validation campaign it returned no confident wrong answers, at roughly 25× lower model cost than an agent loop.

New in 1.2.5 · Symbology & exercise recording

Military symbols on the globe, and a recorder for the exercise feed

Seaglass Globe now draws MIL-STD-2525C symbology and replays scenarios on a timeline. ForgeRelay™, new and opt-in, records live exercise traffic in the same scenario format.

Units draw as real symbols from the first launch, and the suite includes a brigade-advance demo to try the timeline on. ForgeRelay writes every entity, position report, and event into a single GeoPackage library — DIS simulation traffic as ground truth, a Cursor-on-Target feed as one side's picture, never mixed — and runs from the dashboard's Record tab. New in 1.2.5 · Compute broker

GPU workers, brokered

Hand the batch job to the GPUs

Ask ForgeMind for work like “hillshade every tile in this folder” and it becomes one job that GPU workers split between them — on this workstation, or across machines sharing one broker. A crashed worker is restarted and its task handed on; a task that won't fit on any GPU is refused, not attempted.

Licensing & evaluation

Evaluate the Forge suite on one machine

The Forge suite is commercially licensed, and evaluation builds are available to qualified teams. Run the whole suite on one workstation — disconnected if required — and exercise every part of it through one interface.

What you get

The Seaglass Control Center installer: one download that lays down a private Java runtime and the suite — ForgeGIS, ForgeMind, and ForgeData, plus whichever of ForgeGIS Studio, Seaglass Globe, the ForgeRelay exercise recorder, and the compute broker you choose — then runs it from the same window. A bundled offline elevation dataset means the first elevation and slope results need no network. First result in minutes. The build runs under a 90-day evaluation license you accept in the installer.

What you need

  • A Windows x64 workstation. The engines are Java 17+ libraries; the runtime is bundled, so nothing is installed beforehand.
  • A GPU with standard OpenCL drivers. Seaglass Globe needs a real, hardware-accelerated GPU — a remote-desktop session usually can't drive it.
  • 8 GB of RAM for the full suite, and a few gigabytes of disk for a tile cache that grows with use.
  • An AI model. An API key from Claude, OpenAI, Gemini, or Grok — or, for a disconnected site, a model server you run yourself, such as Ollama.

What happens next

Qualified teams receive an evaluation build, and we will walk you through the methodology behind any figure on this site — per-operation timings and the benchmark harness are available to vetted buyers under NDA.
